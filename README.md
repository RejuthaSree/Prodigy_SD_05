🛒 Java Web Scraper 
---

This is a simple Java project that scrapes web information from an e-commerce live site using Jsoup module , and writes the data into a CSV file.

✅ Features
---
-Scraped from: https://scrapeme.live/shop/?orderby=rating

-Extracts product title and price

-Saves results to ScrapperInfo.csv

-Uses BufferedWriter and proper exception handling (try-catch-finally block)
